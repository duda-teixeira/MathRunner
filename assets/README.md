# Imagens do jogo

Coloque aqui os arquivos de imagem usados pelo Math Runner:

- `jogadora (2).png`: personagem atual do jogador. O jogo ajusta seu tamanho mantendo os pixels nítidos.
- `background.png`: imagem de fundo da pista. Recomendado: 960 x 576 px. A imagem e ajustada ao tamanho da janela.

Se esses arquivos ainda nao existirem, o jogo desenha um personagem e um fundo arcade colorido. PNG e o formato recomendado para preservar transparencia no personagem.
